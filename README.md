# 💧 Smart Water Level Indicator

## Description
A simple system to monitor water levels in a tank using sensors, LEDs, and a buzzer to prevent overflow and improve water management.

## Features
- Detects Low, Medium, High levels  
- LED indication  
- Buzzer alert when tank is full  

## Components
Arduino Uno, Sensors, LEDs, Resistors, Buzzer, Jumper Wires

## Working
Sensors detect water levels and activate LEDs. When the tank is full, the buzzer turns ON.

## Usage
Upload code to Arduino and connect the circuit properly.

## Applications
Home tanks, irrigation, water monitoring systems
